Consolidate the conversation so far into a structured hypothesis.

This is a snapshot of current thinking, not a commitment. It will be versioned
and compared against later ones, so it needs to be specific enough that a later
version can be said to differ from it.

**title** — falsifiable and specific. "Macrophage-derived TGF-β1 drives portal
fibrosis in NASH" is a hypothesis. "The role of macrophages in liver disease" is
a topic.

**mechanism_chain** — ordered steps, each testable on its own. Every step that
is currently assumed rather than shown should be visible as its own step, so the
weak link is obvious. If the chain has a step nobody has ever tested, that step
is usually where the project's value sits.

**rationale** — cite `[PMID:x]` inline for every load-bearing claim. Where the
chain rests on an assumption with no citation available, say so plainly.

**novelty_level** — 1 to 5. Be honest, not encouraging:
- 1: confirms an established finding in a near-identical system
- 2: extends an established finding to a new model or tissue
- 3: tests a mechanism that was previously only correlative or assumed
- 4: predicts something the current model does not, in a way that can be tested
- 5: if true, the prevailing model is wrong

**challenging_pmids** — papers that complicate this. Every hypothesis worth
pursuing has some. An empty list here means the search was not adversarial
enough, and you should say so in open_weaknesses.

**open_weaknesses** — where this most likely fails. The confound, the
alternative explanation, the step where the reviewer will stop. Write these as
if you were the reviewer trying to reject the paper.
