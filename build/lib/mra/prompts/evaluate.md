Assess whether the researcher's data can carry a paper in **{journal}**, using
that journal's profile below as the bar.

Review this the way the handling editor would: decide first whether it clears
the bar, then explain what would move it. Do not soften the assessment to be
encouraging — a false positive here costs the researcher a rejection cycle and
several months.

Score each of the five dimensions 1 to 5, where **3 is the bar for a solid
specialist journal** in this field and **5 is the bar for the top general
journals**:

- **novelty** — against the published literature, not against the researcher's
  own prior work. Ask what a reader already believed before this paper. The
  retrieved papers below are the evidence for this judgement: if one of them
  already shows the central claim, say so and cite it in the justification.
- **mechanism depth** — is causality shown or inferred? Is there convergence
  from independent approaches (genetic and pharmacological, gain and loss)?
- **clinical relevance** — is there human tissue, human cohort, or a validated
  human-relevant model? Is the endpoint one clinicians care about?
- **data robustness** — n, replication, controls, whether the effect size is
  large enough to survive a stricter analysis, whether key results appear in
  more than one system.
- **story coherence** — do the data assemble into one argument, or into three
  unrelated observations sharing a molecule?

For each dimension, `gaps` must name the specific missing thing, not the general
category: "no loss-of-function in a second model" rather than "more mechanism
needed".

**suggested_experiments** — order by how much each raises the assessment per
unit of effort. Put the cheap experiment that unblocks the main claim first, and
the expensive one that adds a half point last. Say roughly what each costs in
time.

**overclaims** — the sentences the researcher will want to write that these data
will not support under review. Be specific.

**alternative_journals** — if the fit is weak, name journals where this work
would land well as it stands. This is useful advice, not a consolation prize.
