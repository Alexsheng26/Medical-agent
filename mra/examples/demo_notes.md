## 课题
人 MASH 纤维间隔中 TREM2+ 巨噬细胞与 TGF-β1 的共表达

## 队列
- 人肝穿刺标本 n = 34（MASH F2–F4，NAS ≥ 5）
- 对照肝 n = 11（肝血管瘤旁正常肝）
- 单中心回顾性，2019–2024；女 19 / 男 15；年龄 52 ± 11
- 未做队列外验证

## 主要结果
1. 多重免疫荧光（TREM2 / TGF-β1 / CD68 / α-SMA），纤维间隔区域计数
   - TREM2+ 密度随分期升高：F2 84 ± 31，F3 142 ± 44，F4 176 ± 52 cells/mm²
     （Kruskal-Wallis p = 0.001）
   - TREM2+ 细胞中 TGF-β1 共阳性 61.4%（95% CI 54.2–68.1）；
     CD68+TREM2− 细胞中为 18.9%
   - TREM2+TGF-β1+ 密度与 α-SMA+ 面积相关 r = 0.63，p < 0.001
2. 公共 snRNA-seq 再分析（两个数据集，合计 n = 21 例）
   - TREM2^hi 簇中 TGFB1 表达高于其他髓系簇 log2FC 1.4，adj p = 3e-12
3. 体外：THP-1 源巨噬细胞 + 棕榈酸/胆固醇负荷，TREM2 敲低（siRNA，3 次独立实验）
   - TGFB1 mRNA 下降 42%（p = 0.01）；上清 TGF-β1 蛋白下降 31%（p = 0.04）
   - LX-2 用该上清刺激，ACTA2 表达下降 27%（p = 0.03）
