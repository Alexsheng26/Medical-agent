# 使用建议

装好以后看这份。安装见 [SETUP.md](SETUP.md)；每个功能的原理和取舍见主 [README](../README.md)。

这里写的是**用的时候最容易出问题的地方**，大多是真实使用中碰到过的。

> **它是助手，不替你下结论。** 打分、建议、批评都只是参考，最后由你判断。

---

## 一、第一次用：先跑不花钱的

网页左边栏「工具」里依次点 **试用示例 → 连接自检**，再到「科学对话」随便问一句。
三步都正常，再导入自己的文献和数据。

- 试用示例：导入自带的 8 篇示例文献，不花钱。
- 连接自检：确认 key 能用、服务器连得上、模型能正常返回结构化结果。只调用两次，几乎不花钱。

## 二、文件怎么准备（最容易出问题的地方）

| 东西 | 怎么给 |
|---|---|
| **稿子、审稿意见、实验记录、开题报告** | **Word（.docx）直接选**，不用转。组会 PPT（.pptx）在「审课题」和「评估数据」里也能直接选。老版 .doc、WPS 的 .wps 要先另存为 .docx |
| **数据表** | Excel 先「另存为 → **CSV UTF-8（逗号分隔）**」，再选那个 .csv。直接给 .xlsx 会被拒，并提示怎么另存 |
| **文献** | PDF 可以，但必须是**能选中文字**的那种；扫描件要先做文字识别（OCR）。能从 PubMed 导出 XML 更好：不花钱，卷号、期号、页码也齐全 |

- **Word 里的图片、批注、脚注读不到**，屏幕上会说有几张图、几条批注没读。有没接受的
  修订时，按「全部接受」之后的样子读。
- **为什么 Word 能直接读、Excel 不行**：Excel 里的日期存的是数字、一个文件好几张表、
  合并单元格一个标签管好几行，都能「读出来」但读错，而且不报错。病人数据读错比读不进去危险。

- **给原始数据，不要只给汇总表。** 它会核对说明里的数字和原始数据对不对得上。
- 评估数据时，在「补充说明」里写清楚**每组样本量、研究设计、实验重复了几次**。
  文件里没写的背景，它不知道。

## 三、课题、数据和隐私

- **一个课题建一个「课题」**（网页顶部「课题」那里新建或切换），各课题的文献库互不干扰。
- 所有数据都在 `D:\mra\workspace` 文件夹里（启动器装的位置）。**备份就是复制这个文件夹；
  更新软件时不要动它。**
- 文献和数据都存在本机。但**每次点「开始」调用模型，这一步用到的内容会发给模型服务商**
  （现在是 DeepSeek）。**病人数据先去掉能识别身份的信息**——姓名、住院号、身份证号、
  电话、出生日期等。这个工具不会替你做这一步。
- **API key 不要发到群里，截图也别带上。** 要换 key，用启动器菜单 12。
- 网页只在本机打开，同一个局域网里的其他人也访问不到。

## 四、看结果时要注意

- 提炼卡片里最有价值的是「**局限（含作者未承认的）**」那一栏。
- 读**横断面或观察性研究**时，看一眼「局限」里有没有提**反向因果**（会不会是结局反过来
  影响了暴露）。实测中 DeepSeek 读一篇横断面研究时有一次没提。没提的话，在「科学对话」
  里追问一句「这篇有没有反向因果的可能？」
- **「引用核对」只能保证引用的文献真在库里、不是编出来的，不能保证那篇文献真的支持
  那句话。** 关键的论断要自己点开原文核对。
- 写作结果里出现 `[DATA NEEDED]` 或 `[CITATION NEEDED]`，说明它不肯编数字或引用，
  需要你自己补上。
- 论文里的**表格**大多能读到；**图**读不了。
- 证据强度 1–5 分只是粗略分级，不是结论。

## 五、几个功能的用法要点

**审课题**：学生的开题报告、课题设计或组会 PPT 直接选，可以一次选几个。「背景」里写
**年级、还剩多少时间、实验室有什么**——判断可行性要用，材料里一般不写。看结果时：

- 先看「**我理解的课题**」。和学生想的不一样，说明他的材料没写清楚，这本身就是第一个问题。
- 「**新颖性**」只对着你的文献库判断。学生的方向和你手上的课题不一样时，**给他单独建一个
  课题，先「检索 PubMed」收这个方向的文献，再审**；库里没有相关文献时它会提醒你。
- 每条批评都引了学生材料里的原文。屏幕上提示「在材料里找不到」的那几条，拿给学生之前
  先核对。
- 「组会上可以问的问题」最适合直接拿去用；存成 .md 的审阅意见可以直接发给学生。

**导入并阅读**：「读完直接出分析」默认勾着，导入后马上出提炼卡片，每篇调用一次模型。
只想先收进库、以后再读，就取消这个勾。

**异同比较**：至少选两篇。最有用的用法是拿两篇**结论冲突**的文章，它会判断矛盾是不是
真矛盾（常见的是造模方式不同、干预的细胞群不同，或者一篇只是相关、一篇做了干预）。
课题里有冻结的假说时，最后会说对你的假说意味着什么。

**思维导图**：字数上限由程序来数，超了会先重画一次，还超就从最末端的小分支剪，剪掉了
什么会列出来。存成 `.md` 能导入 XMind，存成 `.opml` 能导入幕布。

**「你的要求」**：思维导图和异同比较都有这一栏，写「侧重方法学」「给本科生讲」
「从临床转化的角度」都可以。

**回复审稿人**：审稿意见和稿子直接选 Word 文件。**发信之前一定看「这封信一旦发出，
你就承诺了这些事」那一段**，确认每一条都做得到、也打算做。存下来的回复信里只有回复
正文；风险提示、哪条意见最要命，都只显示在屏幕上，看完再关窗口。

**参考文献交给 EndNote / Zotero / NoteExpress**：「引用核对」里填导出文件名（如
`参考文献.ris`），只导出库里核对得上的那些，按文中出现顺序；整个文献库用「导出文献」。
EndNote 导入时选「Reference Manager (RIS)」，文本转换选「Unicode (UTF-8)」。

启动器的数字菜单里也有：15 思维导图、16 异同比较、17 回复审稿人、18 导出文献、19 审课题。

## 六、花钱

- DeepSeek 很便宜。最花钱的是「**提炼文献**」，每篇调用一次。第一次用时「只处理前几篇」
  填 3 先试试；那里也可以设花费上限。
- 花费显示「未知」，是因为程序里没有 DeepSeek 的价格表，**不代表没花钱**。实际用量去
  DeepSeek 后台看。
- 重要的判断——投稿前的评估、回复审稿人——如果有 Claude 的 key，可以换成 Claude 再跑
  一遍对照。

## 七、更新、出错、反馈

- **更新**：下载 https://github.com/Alexsheng26/Medical-agent/archive/refs/heads/main.zip
  → 解压 → 把 `Medical-agent-main` **里面的内容**覆盖到 `D:\mra` → `workspace` 文件夹
  保留不动。网页右上角能看到版本号。
- **出错时**：截下整个窗口，包括最后几行字，发过来。
- **觉得哪里判断不对、哪里不好用**：把原话记下来发过来。「思维导图」和「异同比较」就是
  这样加进来的。
